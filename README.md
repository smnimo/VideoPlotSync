# VideoPlotSync

動画の下に時系列プロットを縦に結合し、プロット上に「現在の動画の位置」を赤線で示した動画を作るスクリプトです。
1 本の系列だけでなく、複数の系列を 1 枚の図に重ねることもできます（y 軸を共通にする / 左右の 2 本の y 軸に分ける）。

```
┌──────────────────┐
│      動画         │
├──────────────────┤
│  プロット  ┃赤線   │  ← 動画の再生位置に合わせて動く
└──────────────────┘
```

## 必要なもの

- Python 3.9 以上
- ffmpeg / ffprobe（`ffmpeg`・`ffprobe` コマンドに PATH が通っていること）

## セットアップ

```bash
pip install -r requirements.txt
```

## 使い方

```bash
python video_plot_sync.py --video input.mp4 --csv data.csv -o output.mp4
```

fps とフレーム数は ffprobe で自動的に調べます（調べた値は実行時に表示されます）。

### 入力 CSV

1 行に `index,value` の組を書きます。`index` は動画のフレーム番号です（秒で書く場合は `--index-unit sec`）。
ヘッダ行など数値に変換できない行は自動で読み飛ばします。行の順番はばらばらでも構いません。

```csv
index,value
0,0.12
1,0.15
2,0.20
...
```

既定では 1 列目を index、2 列目を値として使います。列が 3 つ以上ある CSV では、`--index-col` と `--cols` で使う列を選べます（次の節）。
列は**列名**（ヘッダ行の名前）か **0 始まりの列番号**で指定します。先頭の行に数値でないセルがあれば、その行をヘッダ（列名）とみなします（ファイル名などの文字列の列があっても構いません）。
値が空欄や数値でない行は、その系列だけ飛ばします（`--gap` 秒以上抜けていれば線を切ります）。

### 複数の系列を描く

`--cols` に複数の列を並べると、1 枚の図に重ねて描きます。凡例には列名が出ます（`--labels` で変更可）。

**y 軸を共通にする**（同じスケールの系列）:

```bash
python video_plot_sync.py -i face.mp4 -c scores.csv --cols happy sad angry -o out.mp4
```

```
┌──────────────────────────┐
│ ─ happy                  │
│ ─ sad        ┃           │ ← 3 本とも左の y 軸
│ ─ angry      ┃           │
└──────────────────────────┘
```

**y 軸を左右に分ける**（スケールの違う系列。`--right` に挙げた列を右の y 軸に描く）:

```bash
python video_plot_sync.py -i face.mp4 -c scores.csv --index-col frame \
  --cols p_happy happy_neutral --right happy_neutral \
  --ymin 0 --ymax 1 --zero-line -o out.mp4
```

（`scores.csv` の列が `name,frame,...,p_happy,happy_neutral` のように、1 列目がファイル名などの場合は `--index-col` で index の列を指定します。）

```
┌──────────────────────────┐
│1.0 ─ p_happy          2 │
│              ┃        0 │ ← p_happy は左の軸、happy_neutral は右の軸
│0.0 ─ happy_neutral   -4 │
└──────────────────────────┘
```

- 左右の軸に系列が 1 本ずつなら、その軸のラベルは系列名になり、色も系列に合わせます（`--ylabel` / `--ylabel-right` で変更可）。
- 範囲・反転は左右別々に指定できます（`--ymin` / `--ymax` / `--invert-y` と `--ymin-right` / `--ymax-right` / `--invert-y-right`）。
- 左の軸には少なくとも 1 本の系列が必要です（全部を `--right` にはできません）。
- `--right` にだけ書いた列も描きます（`--cols` に入れ忘れても右の軸に出る）。

**複数の CSV**: `--csv` に複数のファイルを並べると、それぞれのファイルから `--cols` の列を描きます（列名はファイルどうしで共通にしておく）。
凡例は `ファイル名: 列名` になります。`--labels` を使う場合は、ファイルごとに `--cols` の順で、ファイル数 × 列数の名前を並べます。

```bash
python video_plot_sync.py -i face.mp4 -c a.csv b.csv --cols p logit --right logit \
  --labels "A: p" "A: logit" "B: p" "B: logit" -o out.mp4
```

**subplot に並べる**: `--sub 行数,列数` を付けると、`--cols` の列を重ねずに 1 列ずつ別のパネル（`subplot(行数, 列数, i)`、左上から横の順）に描きます。赤線はすべてのパネルで同じ時刻に動きます。

```bash
python video_plot_sync.py -i face.mp4 -c scores.csv --cols a b c d e f --sub 2,3 -o out.mp4
```

```
┌────────┬────────┬────────┐
│ a   ┃  │ b   ┃  │ c   ┃  │
├────────┼────────┼────────┤
│ d   ┃  │ e   ┃  │ f   ┃  │  ← x 軸は共通、y 軸はパネルごと
└────────┴────────┴────────┘
```

- パネルのタイトルは列名です（CSV が 1 つなら `--labels` で変更可）。`--title` は図全体のタイトルになります。
- パネル数が `--cols` の列数より多ければ、余ったパネルは消します（少なければエラー）。`2x3` とも書けます。
- y 軸の範囲はパネルごとに自動で決めます。`--ymin` / `--ymax` / `--invert-y` / `--ylabel` / `--zero-line` は全パネルに同じものがかかります。
- CSV が複数なら、同じ列を各 CSV から同じパネルに重ねます（色は CSV ごと。凡例は左上のパネルに 1 つ、名前はファイル名か `--labels`）。
- `--colors` は、CSV が 1 つならパネルごと、複数なら CSV ごとの色になります（CSV が 1 つで `--colors` がなければ全部青）。
- `--right` とは併用できません。
- `--fig-height` を省略すると `2.5 × 行数 + 0.5` inch になります。

色は matplotlib の既定の順（青・オレンジ・緑・赤…）で、`--colors` で変更できます。系列が 1 本のときは従来どおり青で描き、凡例は付けません。
`--mean` / `--median` の平滑化は、すべての系列にかかります。

### fps・フレーム数の自動検出

`--fps` / `--frames` を省略すると、ffprobe で次のように調べます。指定した場合はその値を優先します。

- **fps**: `avg_frame_rate`（平均フレームレート）を使います。
- **可変フレームレートの検出**: `avg_frame_rate` と `r_frame_rate` が 1% 以上違うか、「フレーム数 ÷ 動画の長さ」が fps と 1% 以上違う場合は、可変フレームレート（スマホ動画など）とみなして警告を出します。後者の場合、fps を自動検出しているときは「フレーム数 ÷ 長さ」の実測平均 fps を使います（mkv などはヘッダの `avg_frame_rate` が実際と違うことがあるため）。可変フレームレートの動画では「フレーム番号 ÷ fps = 時刻」が厳密には成り立たないため、赤線が少しずれることがあります。気になる場合は事前に固定フレームレートに変換してください（例: `ffmpeg -i in.mp4 -fps_mode cfr -r 30 out.mp4`）。
- **フレーム数**: メタデータの `nb_frames` → 取れなければパケットを数える（`-count_packets`、デコードしないので速い）→ それも駄目なら `duration × fps` の順に試します。

`--fps` を指定したくなるのは、CSV のフレーム番号が別のツール（顔検出など）の解釈した fps に基づいていて、そちらに合わせたいときです。`--frames` は先頭だけ試しに出力したいとき（例: `--frames 300`）にも使えます。

### オプション

| オプション | 既定値 | 説明 |
|---|---|---|
| `--video`, `-i` | （必須） | 入力動画 |
| `--csv`, `-c` | （必須） | index と値の列の CSV。複数を並べると、それぞれから `--cols` の列を描く |
| `--index-col` | `0` | index の列（列名、または 0 始まりの列番号） |
| `--cols` | `1` | 描く値の列（列名、または 0 始まりの列番号）。複数なら 1 枚の図に重ねる |
| `--right` | なし | 右の y 軸に描く列（`--cols` と同じ書き方） |
| `--labels` | 列名 | 凡例の名前（CSV ごとに `--cols` の順） |
| `--colors` | matplotlib の既定 | 系列の色（例: `--colors tab:orange tab:blue`） |
| `--sub` | なし | `行数,列数`。`--cols` の列を 1 つずつ subplot に並べて描く（`--right` とは併用不可） |
| `--legend` | `upper left` | 凡例の位置（matplotlib の `loc`）。`none` なら付けない。系列が 1 本なら付けない |
| `--fps` | 自動 | 動画の fps（省略時は ffprobe で検出） |
| `--frames` | 自動 | 出力するフレーム数（省略時は動画のフレーム数を検出） |
| `--output`, `-o` | `output.mp4` | 出力動画。すでにある場合は処理を始める前にエラーで止まる |
| `--overwrite`, `-y` | なし | 出力動画がすでにあれば上書きする（入力の動画と同じファイルは指定しても上書きしない） |
| `--index-unit` | `frame` | CSV の index の単位（`frame` / `sec`） |
| `--step` | `0` | 1 画面に表示する秒数。`0` なら動画全体を 1 画面に表示。長い動画では例えば `60` にすると 60 秒ごとに表示区間が切り替わる |
| `--xtick` | `0` | x 軸目盛りの間隔 [秒]。`0` なら自動 |
| `--gap` | `0.5` | この秒数以上データが抜けている所で線を切る。`0` なら全部つなぐ |
| `--mean` / `--median` | なし | 移動平均 / 移動中央値で平滑化 |
| `--window` | `1.0` | 平滑化の窓幅 [秒] |
| `--title` | なし | プロットのタイトル |
| `--ylabel` | `value` | （左の）y 軸ラベル。系列が複数で左の軸に 1 本だけなら、既定はその系列名 |
| `--ymin`, `--ymax` | 自動 | （左の）y 軸の範囲 |
| `--invert-y` | なし | （左の）y 軸を上下反転（順位など、小さいほど上に描きたいとき） |
| `--ylabel-right` | 系列名 | 右の y 軸ラベル（右の系列が 1 本ならその系列名、複数なら空） |
| `--ymin-right`, `--ymax-right` | 自動 | 右の y 軸の範囲 |
| `--invert-y-right` | なし | 右の y 軸を上下反転 |
| `--zero-line` | なし | y = 0 に点線を引く（左右の軸それぞれ） |
| `--line-width` | `3` | 赤線の太さ |
| `--width` | `800` | 出力動画の幅 [px]。動画もプロットもこの幅にそろえる |
| `--fig-width`, `--fig-height` | `15`, `4` | プロットの大きさ [inch]（縦横比が決まる）。`--sub` なら高さの既定は `2.5 × 行数 + 0.5` |
| `--dpi` | `100` | プロットの解像度 |
| `--crf` | `23` | x264 の画質（小さいほど高画質・大きいファイル） |
| `--no-audio` | なし | 音声を含めない（既定では元動画の音声をそのまま入れる） |
| `--threads` | コア数の半分 | 使うコア数。ffmpeg のスレッド数もこれにそろえる。`0` なら制限しない（全コアを使う） |
| `--nice` | `10` | 処理の優先度を下げる量（0〜19）。`0` なら下げない |

### PC が重くなるとき

4K などの高解像度の動画では、元動画のデコードに CPU とメモリを多く使います（4K HEVC では ffmpeg だけで数コア分・数百 MB〜）。
既定ではコア数の半分だけを使い、優先度も下げているので、ほかの作業はできるはずです。それでも重いときは `--threads` を小さくしてください（例: `--threads 2`）。
逆に、専用のマシンで速く終わらせたいときは `--threads 0 --nice 0` にします。

まず `--frames` で短く試すと、所要時間の見積もりにもなります（例: 59.94fps の動画で `--frames 1200` なら先頭約 20 秒）。

### 例

5 分ごとに表示区間を切り替え、1 秒の移動平均をかける:

```bash
python video_plot_sync.py -i face.mp4 -c smile.csv \
  --step 300 --xtick 10 --mean --window 1 --ylabel "smiling intensity" -o face_smile.mp4
```

## 仕組み

- プロットは表示区間が変わるときだけ全体を描画して背景として保存し、フレームごとには背景を戻して赤線だけを描くので高速です。
- プロットのフレームは rawvideo として ffmpeg の標準入力に流し、元動画と同じ ffmpeg の中で縮小・`vstack` で結合するので、中間ファイルは作りません。
- `--sub` のときは `plt.subplots(sharex=True)` でパネルを作り、x 軸の表示区間は全パネルで共有します。赤線はパネルごとに 1 本ずつ描きます。
- 右の y 軸は matplotlib の `twinx()` で作ります。赤線は左の軸に描きます（縦線なので、高さは左の軸の範囲で足ります）。
- 出力の長さは、動画と `--frames` のうち短い方になります（音声も同じ長さで切ります）。元動画は必要な長さだけ読みます。
